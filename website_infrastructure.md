# UNC BCI Project 

We aim to create a project website for the ongoing Brain-Computer-Interface Project led by Professor Raghav in UNC. The project website should have functions similar to these template websites:
1) https://www.epiqc.cs.uchicago.edu/ 
2) https://mindinvitro.illinois.edu/
3) https://carbonconnect.eco/
4) https://modeci.org/

For the sake of easier demo, we will use vercel for deployment of the website, so initialization of the vercel env is vital. 

The website should have these basic pages:
1) Main page, where we can find the overview of the whole project, under main page, there should be a rolling news update section in which we can find all the recent updates of the project
2) Research/Study/Publication page, where details can be found, for example the publications related with the project
3) Product Demo, where we can find a demo of the chips designed, but this may not be usable until later stages of the project
4) People page, this is very important, we need to contain all the information of the people participated in this project. Namely, the page should be divided into different sections, we have the head professor and collaborated engineers, PhD students, graduate students, and then undergraduate student. We may also need to contain information about affilated UNC labs. For each person, it should be like a standard layout of a snapshot of their photo, name, and under that a section for bio. You can decide the layout by yourself.

For easier management in the future, for the fifth page, the Admin page, I want each person is like a card that can be choosed from the slot, so that when we initialize a new "update" of our project on the Main page, we can simply select them and attribute the updates to them.

For this repo, make sure you divide frontend and backend neatly, and you can initialize a workspace for convenience if needed, as I am using VS Code.
